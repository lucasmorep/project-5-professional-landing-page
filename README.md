# 🪒 Professional Landing Page - Vintage Dragon Shaver

This is the **5th project** of my primary developer portfolio. It features a high-conversion landing page for a professional electric shaver, inspired by the iconic "Dragon" design widely recognized across global e-commerce platforms like Shopee and AliExpress.

The project focuses on a **Premium Dark Aesthetic**, blending deep charcoals with metallic gold accents to evoke a sense of luxury and barber-shop quality.

## 🚀 Technologies & Features

I aimed to build a clean, functional, and modern interface using:

* **Semantic HTML5:** For a clean and accessible document structure.
* **Modern CSS3:**
    * **Responsive Design:** Fully optimized for mobile, tablet, and desktop using Media Queries and Flexbox.
    * **Interactive UX:** Smooth `hover` transitions that expand containers and enhance depth through dynamic shadowing.
    * **Typography:** Integrated *Montserrat* via Google Fonts for a sleek, sans-serif look.
    * **Conversion Optimization:** A high-contrast price section and a vibrant green Call-to-Action (CTA) button designed to drive sales.

## 🎨 Design Decisions

* **Matrix Palette:** Colors were sampled directly from the product image to ensure visual harmony.
* **Visual Hierarchy:** Large, bold pricing and glowing titles to immediately capture user attention.
* **Micro-interactions:** Interactive cards that respond to user movement, providing a tactile feel to the digital experience.
